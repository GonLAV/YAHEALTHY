## 🔴 באג חי — לפני כל דיון על פיצ'רים

**`CoachingPage.tsx` קורא ל-endpoint שלא קיים.**

```ts
// services/api.ts:85
export const crmApi = {
  getInsights: (userId) => api.get(`/api/crm/users/${userId}/insights`),
  askCoach:    (userId, msg) => api.post(`/api/crm/users/${userId}/ask`, ...),
};
```

**`/api/crm/*` אינו רשום ב-`index.js` בשום מקום.** קבצי ה-CRM (1,344 שורות) קיימים בדיסק אבל **לא מחוברים** — ובנוסף שבורים בעצמם (מייבאים `./db.js` שלא קיים, ESM בפרויקט commonjs).

**המשמעות:** עמוד "ליווי" — אחד מחמשת המסכים — **מקבל 404 ולא עובד.** זה לא פער מוצר, **זו תקלה בייצור.**

**בעלים:** VLAD מכריע את גורל ה-CRM (ADR-002, פתוח) → פתחיה מחבר או מסיר.
