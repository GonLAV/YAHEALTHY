## משתני סביבה — כשיגיעו

```
META_APP_ID=
META_APP_SECRET=
META_PAGE_ID=
META_PAGE_ACCESS_TOKEN=
IG_BUSINESS_ACCOUNT_ID=
```

🔒 **לא נכנסים ל-`.env.example` עם ערך אמיתי, ולא לריפו.** GitHub Secrets או `.env` מקומי בלבד (`.env` ב-`.gitignore`).

## איך מאמתים את צעד 2 כשהוא נטען שנעשה

```bash
# דורש טוקן של הדף — כלומר רק אחרי צעד 3
curl -s "https://graph.facebook.com/v19.0/{PAGE_ID}?fields=instagram_business_account&access_token=$TOKEN"
```
מחזיר `instagram_business_account.id` → הקישור קיים. מחזיר ריק → **לא קיים**, גם אם נראה מקושר באפליקציה.
