## 3. משתני סביבה

הרשימה המלאה, עם ברירות מחדל ותיאור: `YAHEALTHYbackend/.env.example` ו-`YAHEALTHYFrontend/.env.example`. **ערכים אמיתיים רק במסך המשתנים של ספק האירוח**, לעולם לא בריפו.

באתחול, `utils/config-check.js` כותב ללוג (שמות בלבד, בלי ערכים) אילו פיצ'רים כבויים, ובפרודקשן **מסרב לעלות** אם חסר משתנה חובה.

### Backend — חובה בפרודקשן (השרת לא יעלה בלעדיהם)

| משתנה | הערה |
|---|---|
| `NODE_ENV=production` | מפעיל את בדיקות ה-fail-fast ומסתיר פרטי שגיאות |
| `JWT_SECRET` | 32+ בתים אקראיים. החלפה מנתקת את כל המשתמשים |
| `SUPABASE_URL`, `SUPABASE_KEY` | `ALLOW_MEMORY_DB` אסור בפרודקשן |
| `CORS_ORIGINS` | ה-origin של ה-frontend, מופרד בפסיקים |

### Backend — נדרש לשחרור הזה

| משתנה | בלעדיו |
|---|---|
| `SUPABASE_SERVICE_ROLE_KEY` | `share_cards` (RLS בלי policies) נדחית → יצירת קישור שיתוף נכשלת |
| `APP_URL` | קישורים במיילים ובדף השיתוף מצביעים ל-`localhost:5173` |
| `SHARE_BASE_URL` | אופציונלי — ראו סעיף 4 |
| `SMTP_URL` (+`SMTP_FROM`) | איפוס סיסמה ותקציר שבועי לא נשלחים (פרודקשן מסרב "להעמיד פנים") |

### Backend — אופציונלי, כבר קיים

`PLAN_BASE_AMOUNT`/`PLAN_YONI_AMOUNT` (בלי → "המחיר לפי בקשה" ו-checkout מסרב — **ראו החלטות פתוחות**), `PAYPLUS_*` + `API_PUBLIC_URL` (תשלומים), `WHAPI_*` + `ANTHROPIC_*` (הבוט בוואטסאפ), `WHATSAPP_WEBHOOK_SECRET`, מגבלות קצב חדשות עם ברירות מחדל סבירות: `REFERRAL_*`, `LEAD_RATE_LIMIT_MAX`, `SHARE_LINKS_PER_DAY`, `SHARE_PUBLIC_LIMIT`.

### Frontend

| משתנה | הערה |
|---|---|
| `VITE_API_URL` | ריק = אותו origin (דורש rewrite של `/api/*` ו-`/s/*`, סעיף 4). אחרת — כתובת ה-backend, ואז להוסיף את ה-origin של ה-frontend ל-`CORS_ORIGINS` |

`VITE_SUPABASE_*` הוסרו מה-example — שום קוד לא קורא אותם. נשמר מקום ל-`VITE_VAPID_PUBLIC_KEY` (020).

## 4. ניתוב — `/s/`, `/api/`, ו-deep links של ה-SPA

**הדרישה:** `/s/:token`, `/s/:token/card.svg`, `/s/:token/card.png` מרונדרים **ב-backend** (סורקי קישורים של וואטסאפ/פייסבוק לא מריצים JS ולא שולחים auth). ה-backend בונה את הקישור מ-`SHARE_BASE_URL`, ואם אין — מ-`APP_URL`, כלומר מהדומיין של ה-frontend.

**Backend** (`YAHEALTHYbackend/vercel.json`): כל נתיב נשלח ל-Express — `/api/*` ו-`/s/*` עובדים שם כבר היום.

**Frontend** (`YAHEALTHYFrontend/vercel.json`, חדש): כל נתיב שאינו `/api/` או `/s/` מוגש כ-`index.html`, כך ש-`/onboarding`, `/invite`, `/achievements`, `/admin/marketing` (ובהמשך `/guides`) נפתחים ישירות ולא מחזירים 404. קבצים סטטיים (`/assets/*`) מוגשים לפני ה-rewrite.

בוחרים **אחת** משתי תצורות:

**א. שני דומיינים (בלי לגעת בקונפיגורציה):**
`SHARE_BASE_URL=https://<backend-host>`, `VITE_API_URL=https://<backend-host>`, ו-`CORS_ORIGINS` כולל את ה-frontend. קישורי שיתוף יהיו על דומיין ה-backend.

**ב. דומיין אחד (קישורים יפים יותר):** להוסיף ל-`YAHEALTHYFrontend/vercel.json`, **לפני** ה-rewrite הקיים, עם הכתובת האמיתית:

```json
{ "source": "/api/:path*", "destination": "https://<backend-host>/api/:path*" },
{ "source": "/s/:path*",   "destination": "https://<backend-host>/s/:path*" },
```

ואז `VITE_API_URL` ריק ו-`SHARE_BASE_URL` לא מוגדר. (לא נכתב מראש בקובץ: Vercel לא מקבל משתני סביבה ב-rewrites, וכתובת מומצאת הייתה שוברת את הפריסה בשקט.)

> ⚠️ **`^/s/` ולא `/s`.** קידומת `/s` בלי לוכסן תופסת גם את `/signup` ואת `/sleep`. זה הדפוס ב-`vite.config.{js,ts}` (proxy בפיתוח), ב-rewrite של ה-frontend, ובכל nginx/CDN: `location ^~ /s/ { proxy_pass http://backend; }`.

**Docker (`docker-compose.base44.yml`) — פיתוח בלבד:** Vite dev עם proxy ל-`/api` ול-`^/s/`. `vite preview` לא משתמש ב-proxy הזה.

## 5. בדיקות עשן

```bash
API=https://<backend-host>      # או ה-frontend בתצורה ב
APP=https://<frontend-host>

# בריאות
curl -fsS $API/api/health

# שיווק — תוכניות (amount=null כשאין מחיר) וליד (201; הסכמה חובה)
curl -fsS $API/api/marketing/plans
curl -fsS -X POST $API/api/marketing/leads -H 'Content-Type: application/json' \
  -d '{"email":"smoke+'$(date +%s)'@example.com","consent":true,"lang":"he"}'

# הפניות — קוד לא קיים מחזיר תשובה תקינה, לא 500
curl -sS $API/api/referrals/validate/NOPE123

# הרשמה + onboarding + engagement (טוקן מההרשמה)
TOKEN=$(curl -fsS -X POST $API/api/auth/signup -H 'Content-Type: application/json' \
  -d '{"email":"smoke+'$(date +%s)'@example.com","password":"smoke-test-pass-1","name":"Smoke"}' | node -pe 'JSON.parse(require("fs").readFileSync(0)).token')
curl -fsS $API/api/onboarding -H "Authorization: Bearer $TOKEN"          # completed:false
curl -fsS $API/api/engagement/summary -H "Authorization: Bearer $TOKEN"
curl -fsS $API/api/referrals/me -H "Authorization: Bearer $TOKEN"

# שיתוף — יצירת קישור ופתיחה ציבורית (200 + og:title)
LINK=$(curl -fsS -X POST $API/api/share/weekly-card/link -H "Authorization: Bearer $TOKEN" \
  -H 'Content-Type: application/json' -d '{"lang":"he","tz":"Asia/Jerusalem"}' | node -pe 'JSON.parse(require("fs").readFileSync(0)).url')
echo $LINK                                   # הדומיין הנכון? (סעיף 4)
curl -fsS $LINK | grep -o '<meta property="og:title"[^>]*>'
curl -fsSI $LINK/card.svg | grep -i content-type   # image/svg+xml

# staff בלבד — משתמש רגיל מקבל 404 (לא 403)
curl -sS -o /dev/null -w '%{http_code}\n' $API/api/analytics/funnel -H "Authorization: Bearer $TOKEN"   # 404

# SPA deep links — 200 ו-HTML של Vite, לא 404
for p in / /onboarding /invite /achievements /admin/marketing /signup /sleep; do
  printf '%s ' $p; curl -sS -o /dev/null -w '%{http_code}\n' $APP$p; done
# /signup ו-/sleep חייבים להחזיר את ה-SPA, לא את ה-backend
```

בדפדפן: הרשמה → מופנה ל-`/onboarding` → סיום → דשבורד → "שתפו את השבוע" → הדבקת הקישור בוואטסאפ ובדיקת תצוגה מקדימה. משתמש staff (`users.is_staff = true`) → `/admin/marketing` נטען.

**אחרי הבדיקה:** למחוק את משתמשי וליד ה-smoke (`email like 'smoke+%@example.com'`) כדי שלא יזהמו את לוח האנליטיקס.

## 6. החלטות מוצר פתוחות (לא הוכרעו בשחרור הזה)

1. **מחירים — שני מקורות סותרים.** הקוד (`routes/payments.js`) מכיר שני מסלולים חודשיים, `base` ו-`yoni`, שמחירם מגיע מ-`PLAN_BASE_AMOUNT`/`PLAN_YONI_AMOUNT` (ה-example הישן הציע 150/250). `docs/product-truth.md` מתמחר אחרת: אפליקציה ₪49, שף ₪149, ליווי ₪1,290, שילוב ₪1,690. **עד החלטה — להשאיר את המשתנים ריקים**; דף הנחיתה יציג "המחיר לפי בקשה" ו-checkout יסרב במקום לגבות סכום שאיש לא החליט עליו.
2. **כפתורי התמחור בדף הנחיתה לא מתחילים תשלום** — הם מובילים להרשמה. חיבור ל-`POST /api/payments/checkout` תלוי בהחלטה 1.
3. **תגמולי הפניות נרשמים ולא מיושמים.** `referral_rewards` נכתבת (14 ימי פרימיום, עד 10 הפניות), אבל שום דבר לא מאריך מנוי או מזכה בחיוב. לא לפרסם "חודש חינם על כל חבר" לפני שזה מחובר.

## תוספת: הודעות מחזור חיים (מיגרציה 018)

מוזג אחרי כתיבת המסמך: הודעות lifecycle (טיפוח לידים, קליטה, רצף בסכנה, החזרה). יש להריץ את `018_lifecycle_messaging.sql` אחרי 016 ולפני 019, ולהגדיר `SMTP_URL` ו-`LIFECYCLE_TOKEN_SECRET` (בלעדיו קישורי ההסרה נחתמים ב-`JWT_SECRET`, והחלפתו תשבור קישורים שכבר נשלחו). הג'וב השעתי לא רץ על Vercel.
