# 8. 🔴 שער הבטיחות — הזרימה החשובה ביותר כאן

**זו הזרימה שמגנה עליך. תבנה אותה ראשונה.**

**Trigger — Keywords (העתק את כולן):**

```
היריון, בהריון, הריון, מניקה, הנקה,
סוכרת, סוכרתי, סוכרתית, אינסולין,
אנורקסיה, בולימיה, הפרעת אכילה, הקאות,
תרופות, כרוני, כרונית, בלוטת התריס, תירואיד,
לב, כליות, כבד, לחץ דם,
בריאטרי, קיצור קיבה, שרוול,
בת 16, בן 16, בת 17, בן 17, קטין, הילד שלי, הבת שלי, הבן שלי,
אלרגיה, אלרגי, אלרגית, רגישות למזון, צליאק, גלוטן, אגוזים, בוטנים
```

**⚠️ שתי ההוספות האחרונות אינן אופציונליות:**

- **אלרגיה אינה "העדפה תזונתית".** זרימה שמציעה תחליף עלולה לפגוע פיזית. **עצירה מלאה.**
- **"הילד שלי" / "הבת שלי"** — הדגל חל על **מי שישתמש במוצר, לא על מי שכותב.** "אני ההורה ואני מאשרת" לא מכריע אותו.

```
תודה ששיתפת — זה חשוב, ואני שמח/ה שאמרת.

בגלל מה שסיפרת, אני מעדיף/ה שאיש מקצוע יתייחס לזה אישית
ולא שאענה לך כאן אוטומטית. אעביר את הפנייה ונחזור אליך.

ואם זה משהו דחוף — כדאי לפנות לרופא/ה.
```

**ב-ManyChat:** **Tag: `safety-flag`** → **Notify Admin (דחוף)** → **Pause Automation**

> 🔴 **הזרימה הזו עוצרת את האוטומציה ולא מציעה מוצר. בלי יוצא מן הכלל.**
> אין כפתור "בכל זאת ספר לי על המחירים". אין "אפשר להמשיך".
> **גם כשזו מכירה בטוחה — עוצרים.**
